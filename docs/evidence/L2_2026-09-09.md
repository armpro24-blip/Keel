## Observations by category (recorded, no mechanism proposed)

1. **Fuse (harness; dominant friction).** `max_turns = 32` was reached
   twice: once while the model was writing `test_state.py`, once when the
   suite was already green but the summary had not been written. Each
   fuse ended the run with an error and required an operator `Continue`;
   without that budget the task would not have completed under the default
   fuse. Context was 56.8k tokens at the end, far from the window; the fuse
   was the binding limit, not the context. The protocol pre-registered
   exactly this: "if the fuse or context behavior becomes the failure, that
   is evidence."
2. **Output truncation on test runs (PIRA tool behavior).** `pira_ctx`
   automatic mode withheld most of the failing test output several times
   (`unselected=10265 B/121 lines`), so the model ran tests one by one and
   printed `render_table` output with `python -c` to align column widths.
   A sizeable share of the 63 shell calls were such probes; this friction
   contributed directly to the call count and thus to the fuse. The model did
   not use `pira_ctx search`/`range` on the retained result ids, nor
   `mode: exact`.
3. **Repeated reads of large files (model).** `test_cli.py` was read six
   ways (whole, numbered, ranges, tail); one range read failed on
   PowerShell syntax.
4. **`edit_file`.** 15/18 exact; the three errors were each recovered in
   one step (missing review; zero match after a re-read; identical texts).
   Largest replaced block 1,350 bytes; largest insertion 2,644 bytes. No
   multi-match.
5. **Handshake.** 16/16 announced before execution; one missing-review
   denial recovered; one superfluous review on a read-only call, ignored as
   designed.
6. **Malformed calls (model).** 2 `argv`-as-string shell calls, both
   corrected on the next turn; well below L1's 8.
7. **Policy loads.** 5 `read_pira_policy` calls, as in L1-R2 (0 in L1-R1
   ask mode).
8. **Narration (model).** The final summary reported "33 tests" against an
   actual 54.
9. **Windows command friction (model).** First `dir`-style call exit 1;

10. **Test preservation (formal).** 42/42 kept, 12 added; the L1-R1
